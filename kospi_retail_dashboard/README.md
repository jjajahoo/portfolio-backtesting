# KOSPI × 개인 투자자 수급 대시보드

KOSPI 지수와 **개인 순매수 · 개인 거래량 · 투자자예탁금 · 신용융자 잔고**를 같은 날짜 축에 놓고 보는 Streamlit 앱입니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 📈 KOSPI + 지표 | KOSPI(라인/캔들, 로그 축) 아래에 지표 패널을 쌓아 같은 날짜로 비교. 마우스를 올리면 그날의 모든 값이 함께 표시 |
| 🔀 한 차트로 비교 | 단위가 다른 지표를 z-score 또는 "기간 시작 = 100"으로 맞춰 한 차트에 겹쳐 보기 |
| 🔗 상관관계 | 각 지표와 KOSPI 같은 기간 / 향후 N일 수익률의 상관계수 |
| 🗂 데이터 | 전체 표 + CSV 다운로드 |
| ℹ️ 지표 설명 | 지표 정의와 출처 |

상단 요약: KOSPI, 기간 개인 순매수 합계, 예탁금, 신용융자, 신용융자/예탁금 비율, **개인 투자심리 지수**

**개인 투자심리 지수** = 아래 요소의 z-score 평균 (사용 가능한 요소만 반영)
- 개인 순매수 N일 이동합
- 개인 거래대금 비중 (개인 매수+매도 ÷ 시장 전체)
- 투자자예탁금 N일 증가율
- 신용융자 N일 증가율

## 데이터 출처

| 데이터 | 1순위 | 대체 |
|---|---|---|
| KOSPI 지수 | KRX (pykrx) | 네이버 차트 |
| 개인 순매수 | KRX (pykrx) | 네이버 투자자별 매매동향 |
| 개인 거래량 · 거래대금 비중 | KRX (pykrx) | 없음 |
| 투자자예탁금 · 신용융자 | 금융투자협회 FreeSIS | 네이버 증시자금동향 |

> pykrx 는 KRX 정보데이터시스템(data.krx.co.kr) **로그인이 필요**합니다. 계정이 없으면 개인 순매수는 네이버에서 가져오고,
> 개인 거래량·거래대금 비중 패널은 표시되지 않습니다.
> 예탁금·신용융자는 보통 1~2 영업일 늦게 공표됩니다.

## 실행

```bash
pip install -r kospi_retail_dashboard/requirements.txt
streamlit run kospi_retail_dashboard/app.py
```

KRX 계정은 사이드바에 입력하거나, `kospi_retail_dashboard/.streamlit/secrets.toml.example` 을
`secrets.toml` 로 복사해 넣어 두면 자동으로 사용합니다 (환경변수 `KRX_ID`, `KRX_PW` 도 가능).

인터넷 연결 없이 화면만 확인하려면 사이드바에서 **데모 (가상 데이터)** 를 선택하세요.
직접 모은 데이터는 **CSV 업로드**로 불러올 수 있습니다 (양식 다운로드 버튼 제공).

## KOSPI 가격 시뮬레이터 (`simulator.py`)

KOSPI를 원하는 수준으로 옮겨 보고 **밸류에이션**과 **기술적 지표**가 어떻게 바뀌는지 보는 별도 앱입니다.

```bash
streamlit run kospi_retail_dashboard/simulator.py
```

| 입력 | 설명 |
|---|---|
| 가상 KOSPI | 지수(pt)로 입력하거나 변동률(%) 슬라이더·프리셋 버튼(±5/10/20%)으로 조정 |
| 도달 기간 | 몇 거래일에 걸쳐 그 수준에 도달하는지 (1 = 다음 거래일) |
| 경로 모양 | 일정한 비율 / 변동성 반영(최근 60일 변동성으로 오르내리다 목표에서 끝나는 무작위 경로) |

| 탭 | 내용 |
|---|---|
| 📊 밸류에이션 | 현재 vs 가상 PER·PBR·배당수익률·일드갭·시가총액/GDP, 과거 N년 중 위치(백분위), 목표 배수 → KOSPI 환산표, PBR·PER 밴드 차트 |
| 📈 기술적 지표 | 가격+이동평균(5·20·60·120)+볼린저, RSI, MACD, 스토캐스틱 차트(가상 구간 표시), 지표 비교표, 가상 구간에서 생기는 신호(골든·데드크로스 등) |
| 🪜 주요 가격대 | 다음 거래일 종가가 얼마면 RSI 70/30, 이동평균 이탈·회복, 골든·데드크로스, MACD 교차, 볼린저 상·하단, 52주 신고가가 되는지 역산한 가격 사다리 |

- **밸류에이션 가정**: 기업 이익·순자산·배당은 그대로이고 지수만 움직인다고 봅니다. 1포인트당 EPS·BPS·배당은
  KRX가 발표한 KOSPI PER·PBR·배당수익률로 역산합니다 (EPS = 종가 ÷ PER).
- **KRX 로그인**이 있으면 PER·PBR·배당수익률 이력과 시가총액을 자동으로 받아 과거 대비 위치와 밴드 차트를 그립니다.
  없으면 가격은 네이버에서 받고, 현재 PER·PBR·배당수익률을 사이드바에 직접 입력합니다.
- 국고채 10년 금리, 명목 GDP, 선행 PER은 사이드바에서 입력합니다.
- 가상 거래일은 주말만 제외합니다 (공휴일 미반영). 인터넷 없이 보려면 **데모 (가상 데이터)** 를 선택하세요.

### 웹페이지 버전 (`web/`)

설치 없이 브라우저에서 쓰는 같은 시뮬레이터입니다 (`web/simulator_page.html`).
실제 데이터를 넣은 HTML 파일 하나를 만들려면 KRX·네이버에 접속되는 컴퓨터에서:

```bash
python kospi_retail_dashboard/web/build_web.py --years 5 --out kospi_simulator.html
```

`KRX_ID`·`KRX_PW` 환경변수가 있으면 PER·PBR·배당수익률·시가총액 이력도 들어갑니다.
데이터가 없는 페이지는 KRX [11003] 개별지수 시세 추이·[11007] PER/PBR/배당수익률 CSV나 붙여넣은 표를 직접 불러올 수 있습니다.

## 파일

- `app.py` — Streamlit 화면
- `data_sources.py` — KRX / 금융투자협회 / 네이버 수집, 단위 통일(원·주), 날짜 정렬
- `indicators.py` — 파생 지표, 투자심리 지수, 상관관계, 데모 데이터
- `charts.py` — Plotly 차트
- `simulator.py` — KOSPI 가격 시뮬레이터 화면
- `simulation.py` — 가상 경로, 기술적 지표, 다음 거래일 가격 역산, 밸류에이션 계산
- `sim_charts.py` — 시뮬레이터 차트
- `web/simulator_page.html` — 웹페이지 버전, `web/build_web.py` — 실제 데이터를 넣은 HTML 만들기

본 앱의 지표는 참고용이며 투자 판단의 근거가 아닙니다.
