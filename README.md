# 📈 포트폴리오 백테스터

과거 데이터로 내 투자 방법을 미리 시험해 보는 웹 앱이에요.
한국·미국 **주식과 ETF**를 섞어서 넣을 수 있고, 샤프 비율이나 MDD 같은 어려운 용어는
**쉬운 말과 예시**, 그리고 **내 결과 숫자를 넣은 맞춤 설명**으로 풀어서 보여줘요.

## 할 수 있는 것

- **종목·비중 입력**: 한국 종목은 6자리 코드(`069500`), 미국 종목은 티커(`SPY`)
- **예시 포트폴리오**: 주식 60 : 채권 40, S&P500 하나만, 올웨더, 영구 포트폴리오, 한국형 60:40, 국내 상장 ETF 분산
- **리밸런싱**: 안 함 / 매월 / 분기 / 매년
- **기준 통화**: 원화 또는 달러 (미국 종목을 원화로 보면 환율 효과까지 반영)
- **거래비용, 예금 금리(무위험 수익률)** 설정
- **결과 지표**: 최종 금액, 연평균 수익률(CAGR), 최대 낙폭(MDD), 샤프 비율, 총 수익률, 변동성, 가장 긴 회복 기간, 최악의 해
- **비교 대상(벤치마크)** 과의 차이
- **그래프**: 자산 성장, 낙폭, 연도별 수익률
- **종목별 비교표**: 각 종목에 전부 넣었다면 어땠는지
- **용어 사전**: 용어마다 한 줄 뜻, 비유, 숫자 예시
- 결과 데이터 CSV 내려받기

## 실행하기

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

브라우저에서 http://localhost:8501 이 열려요.

### 인터넷에 올리기 (무료)

1. 이 저장소를 GitHub에 올려 둔 상태에서 https://share.streamlit.io 에 GitHub 계정으로 로그인
2. **Create app** → 저장소와 브랜치 선택 → Main file path에 `streamlit_app.py`
3. **Deploy**를 누르면 몇 분 뒤 나만의 주소가 생겨요.

## 테스트

```bash
pip install -r requirements-dev.txt
pytest
```

테스트는 가짜 시세 데이터를 쓰기 때문에 인터넷 연결 없이 돌아가요.

## 구조

| 파일 | 하는 일 |
|---|---|
| `streamlit_app.py` | 화면 (입력, 결과, 용어 사전, 사용법) |
| `backtester/engine.py` | 백테스트 계산 (리밸런싱, 거래비용, 지표) |
| `backtester/market_data.py` | Yahoo Finance에서 가격 받기, 한국/미국 코드 처리, 환율 변환 |
| `backtester/glossary.py` | 용어 설명, (?) 도움말, 내 결과 맞춤 설명 |
| `backtester/charts.py` | 그래프 |
| `backtester/catalog.py` | 자주 쓰는 종목 목록과 예시 포트폴리오 |
| `backtester/formatting.py` | `1억 2,345만 원` 같은 숫자 표시 |

## 계산 방법

- 가격은 Yahoo Finance의 **수정 종가**(배당 재투자 반영)를 써요.
- 한국과 미국은 휴장일이 달라서, 쉬는 날은 직전 가격으로 채워요.
- 모든 종목(과 비교 대상)의 데이터가 있는 날부터 계산해요.
- 리밸런싱은 새 달/분기/해의 첫 거래일에 해요.
- 거래비용은 처음 살 때와 리밸런싱할 때 사고판 금액에 붙어요.
- 변동성과 샤프 비율은 **월 수익률**로 계산해요 (한국·미국 시장 시간 차이로 생기는 왜곡을 줄이려고).
- 수익률은 실제로 넣은 돈(처음 투자금) 기준이에요.

## 꼭 알아두세요

- 과거 성과가 미래 수익을 보장하지 않아요.
- 세금(양도소득세, 배당소득세 등)은 반영하지 않았어요.
- 데이터는 Yahoo Finance에서 가져오며 오류나 빠진 날이 있을 수 있어요.
- 이 앱은 공부용 도구이고, 투자 권유가 아니에요.
