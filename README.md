# QQQ 점수 실험실

나스닥100(QQQ)을 기술적·금리·경기·가치평가 지표로 점수화하고,
**조건에 해당했던 구간을 차트에 표시한 뒤 그 이후 수익률을 통계로** 보여주는 Streamlit 앱.

예) 사이드바에 `기준금리 값 ≥ 4` 를 넣으면
- 차트에 기준금리가 4% 이상이었던 기간이 음영으로 표시되고
- '조건 통계' 탭에 그 기간에 샀다면 1·3·6·12개월 뒤 수익률이 평균/중앙값/승률/최대하락으로 나오며 전체 기간과 비교된다.

## 실행

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Streamlit Community Cloud에 이 레포를 연결하면(메인 파일 `streamlit_app.py`) 웹·휴대폰에서 바로 볼 수 있다.

## 화면

| 탭 | 내용 |
|---|---|
| 📈 차트 | QQQ 수정주가 + 볼린저밴드/이동평균 + 조건 구간 음영, 아래에 고른 지표(최대 6개)와 조건 기준선 |
| 📊 조건 통계 | 조건 해당일 / 구간 시작일 / 전체의 이후 수익률 비교, 구간 목록 |
| 🎯 점수 검증 | 종합점수 구간별 이후 수익률, 지표별 순위상관(IC) — 조정 구간 vs 검증 구간 |
| ⚙️ 지표 설정 | 지표 켜기/끄기, 파라미터, 점수 방식(백분위/구간), 방향, 가중치 |
| 📋 현재 상태 | 지표 현재 값·점수·기여도, 데이터 기준일, 계산 결과 CSV |

사이드바: 조건 빌더(AND/OR, ≥ ≤ > < 사이 바깥), 검증 구간 분리, 설정 JSON 저장/불러오기, 사용자 지표 CSV 업로드.

## 지표 (24개)

- **기술적**: RSI, 볼린저 %B, 이동평균 이격도, 고점 대비 낙폭, 이동평균 교차, MACD 히스토그램, 스토캐스틱, 모멘텀, 변동성
- **금리**: 기준금리, 기준금리 변화(인상기/인하기), 10년물, 장단기 금리차, 실질금리
- **경기·심리**: VIX, 신용스프레드, CPI 상승률, 실업률 상승폭, M2 증가율, 연준 총자산 증가율, 달러지수 변화율, 금융여건지수
- **가치평가**: 장기추세 괴리(나스닥100 로그 추세선 대비), 사용자 지표(CSV — 예: PER)

새 지표 추가: `qqq_score/indicators.py`에 계산 함수를 만들고 `INDICATORS`에 `Indicator(...)` 한 줄을 더하면 설정·차트·조건·통계에 자동으로 붙는다.

## 백테스트가 부풀려지지 않게 한 것

- **미래 정보 차단**: 점수(백분위 포함)는 그 시점까지의 데이터로만 계산. 경제지표는 발표 지연(CPI 45일, 실업률 35일, M2 60일 등)만큼 늦춰서 사용. `tests/test_core.py::test_no_lookahead`가 모든 지표에 대해 "미래 데이터를 지워도 과거 값이 같은지" 검사한다.
- **조정/검증 구간 분리**: 설정은 조정 구간 통계를 보며 만들고, 검증 구간에서도 통하는지 확인. 조정 구간 표본은 이후 수익률 계산 기간이 검증 구간에 걸치지 않는 날만 쓴다.
- **겹치는 표본 주의**: '조건 해당일'은 매일을 표본으로 세서 표본수가 커 보인다. '구간 시작일'(구간마다 한 번)이 더 보수적인 비교.

남은 한계: 경제지표 수정치(최초 발표치가 아닌 수정된 값)를 쓴다. 무료 데이터라 시세는 약 15분 지연이다.
